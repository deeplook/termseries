# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by opening a private issue on
[GitHub](https://github.com/deeplook/termseries/security/advisories/new).

Do not create public GitHub issues for security vulnerabilities.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
