# Static and interactive comparisons

Nine examples compare real Matplotlib PNG output with Plotly charts using identical
prepared observations, chart modes, gap policies, timezones and initial time bounds.
The page uses deterministic synthetic data and includes its images and JavaScript.

[Open the interactive gallery](examples/browser-examples.html)

The paired examples cover multiple series, indexed values, drawdown, returns,
connected versus visible gaps, step lines, seasonal overlays, and the repeated
hour at a daylight-saving transition. Use Reset view to return a browser chart to
its original comparison bounds after zooming or hiding a series. Pairs stack
vertically on narrow screens.

The gallery is about 6 MiB because it embeds the chart library and nine rendered
images. You can save the page for offline use. It loads on demand when you follow
the link; it is not included in every documentation page.

See [Browser charts and Python](browser.md) for integration examples and
[Validation and performance](validation.md) for measured limits.
