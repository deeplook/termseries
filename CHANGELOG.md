## [0.1.0] - 2025-02-10

### Added
- Yahoo Finance data source with configurable period
- Chart modes: absolute, indexed, log, drawdown, returns, relative
- Terminal inline image support: Kitty, iTerm2, Sixel
- PNG file fallback output
- Interactive Textual TUI with dropdowns
- Clipboard copy support (macOS, Windows, Linux)
- Configurable aspect ratio and color cycles
- Dark/light terminal theme detection
